## Option 1 — Use Nginx Ingress

### 1. Install Nginx Ingress controller

Run:

```bash
kubectl apply -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/controller-v1.12.1/deploy/static/provider/cloud/deploy.yaml
```

Then check:

```bash
kubectl get pods -n ingress-nginx
kubectl get svc -n ingress-nginx
```

You should see something like:

```text
ingress-nginx-controller   LoadBalancer or NodePort
```

If you are running this locally or on a VPS without cloud load balancer, the `EXTERNAL-IP` may stay pending. That is normal unless you install MetalLB or use NodePort.

## 2. Create Ingress for your CEERAT apps

Create a file:

```bash
nano ceerat-ingress.yaml
```

Put this inside:

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: ceerat-frontend-ingress
  namespace: ceerat-frontend
  annotations:
    nginx.ingress.kubernetes.io/rewrite-target: /
spec:
  ingressClassName: nginx
  rules:
    - host: ceerat.local
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: ceerat-web-ui
                port:
                  number: 3000

    - host: customer.ceerat.local
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: ceerat-customer-ui
                port:
                  number: 3005

    - host: admin.ceerat.local
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: ceerat-admin-ui
                port:
                  number: 3010
```

Apply it:

```bash
kubectl apply -f ceerat-ingress.yaml
```

Check it:

```bash
kubectl get ingress -A
```

## 3. Point your computer to the cluster

For local testing, find your node IP:

```bash
kubectl get nodes -o wide
```

You may see something like:

```text
192.168.1.50
```

Then edit your Mac hosts file:

```bash
sudo nano /etc/hosts
```

Add:

```text
192.168.1.50 ceerat.local
192.168.1.50 customer.ceerat.local
192.168.1.50 admin.ceerat.local
```

Then open:

```text
http://ceerat.local
http://customer.ceerat.local
http://admin.ceerat.local
```

If this is **k3s**, it may already come with **Traefik ingress** installed. Check:

```bash
kubectl get pods -n kube-system

```

If you see:

```text
traefik
```

Then you may not need Nginx. You can use Traefik instead.

Your Ingress would look almost the same, but use:

```yaml
ingressClassName: traefik
```

instead of:

```yaml
ingressClassName: nginx
```


## Best setup for your CEERAT apps

Use this:

```text
Nginx Ingress or Traefik
+
domain names
+
HTTPS certificate
```

Example final URLs:

```text
https://ceerat.com
https://customer.ceerat.com
https://admin.ceerat.com
```

Backend and database should stay internal:

```text
postgres      do not expose publicly
typesense     keep internal unless protected
user-service  usually internal/API only
agent-service usually internal/API only
```

For your next command, run:

```bash
kubectl get ingressclass
```

If it shows `traefik`, use Traefik. If it shows nothing, install Nginx Ingress.
